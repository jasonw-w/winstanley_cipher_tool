# winstanley_cipher_tool
Toolbox for National cipher challenge

## Usage

Run the tool with Python and pass the cipher name, text, shift, and mode:

```bash
python main.py <cipher> <text> <shift> <mode>
```

Example:

```bash
python main.py caesar abcde 3 encrypt
python main.py caesar defgh 3 decrypt
```

Current available cipher:

- `caesar`
